# SuperDuper

An infinite-canvas note app for the Supernote Nomad.

**Use at your own risk.** This is an unofficial, independently-built app that talks to
undocumented internals of the Nomad's firmware. It is provided as-is, with no warranty of
any kind — no guarantee it won't lose data, misbehave, or stop working after a firmware
update.

## Install

Download the APK from [Releases](../../releases) and sideload it: on the Nomad,
**Settings > Security & Privacy > Sideloading > ON**, then install the downloaded file.
